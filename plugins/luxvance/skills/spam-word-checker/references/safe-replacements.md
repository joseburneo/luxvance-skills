# Safe Replacement Patterns

When a banned word or risky pattern fires, prefer one of these substitutions. If nothing fits, rewrite the line so the operational meaning is explicit instead of fuzzy hype.

## CTAs

| Banned | Safe |
|---|---|
| `free consultation` | `open to a short conversation` |
| `book a call` | `worth a quick look?` / `worth 15 min next week?` |
| `schedule a demo` | `happy to walk through how it would work for you` |
| `click here` | `let me know and I can send it over` |
| `sign up free` | `set you up with a sandbox account` |
| `get started now` | `if useful, we can start with [specific small thing]` |
| `apply now` | `if relevant, happy to send the details` |

## Pressure / urgency

| Banned | Safe |
|---|---|
| `act now` | `if relevant, happy to send details` |
| `limited time` | `not sure if this is timely for you` |
| `last chance` | rewrite as a question — `worth one more look?` |
| `expires today` | drop the urgency, lead with the value |
| `hurry up` | drop |
| `time limited` | `if this is the right month for you` |

## Hype

| Banned | Safe |
|---|---|
| `amazing` | `the part that surprised our team was [specific]` |
| `fantastic` | `[specific result]` |
| `incredible deal` | `the math worked out to [specific number]` |
| `unbeatable` | `competitive on [specific dimension]` |
| `the best` | `one of the [specific dimension] approaches we've run` |
| `revolutionary` | `[specific mechanism]` |
| `game-changer` | `[specific business outcome]` |

## Outcome claims

| Banned | Safe |
|---|---|
| `guaranteed results` | `this may be relevant depending on your situation` |
| `100% guaranteed` | `we typically see [range], with [caveat]` |
| `increase revenue` | precise business outcome (e.g. `help support liquidity`, `lift qualified pipeline`) |
| `save money` | precise business outcome (e.g. `reduce processing cost per file`) |
| `get more customers` | `bring qualified meetings on calendar` |
| `double your X` | precise number with a real benchmark |

## Brand-guidelines bans (rewrite, no direct substitution)

These have no clean swap — rewrite the line so the verb is no longer needed.

| Banned | Approach |
|---|---|
| `synergy` / `synergies` | rewrite to describe the actual combined effect |
| `leverage` | use `use` or describe the mechanism |
| `empower` | rewrite to describe what changes for the person |
| `unlock` | rewrite to describe what becomes possible |
| `ecosystem` | use the specific thing (network, partners, tools) |
| `world-class` | rewrite with a specific proof (named clients, numbers) |
| `cutting-edge` | rewrite with the specific technique |

## Flattery openers (banned by brand-guidelines)

| Banned | Approach |
|---|---|
| `I've been following your work` | replace with a specific observation about their company |
| `big fan of [Company]` | drop — go straight to the observation |
| `longtime admirer` | drop |
| `huge respect for what you've built` | replace with a specific data point about their company |

## Em-dashes (Luxvance brand bans them)

| Original | Rewrite |
|---|---|
| `Our team — the one in Madrid — built this` | `Our Madrid team built this` (or use commas) |
| `Three things matter — speed, depth, cost` | `Three things matter: speed, depth, cost` |
| `We help — at scale — outbound teams` | `We help outbound teams at scale` |

## Greeting prefix before first name

| Banned | Approach |
|---|---|
| `Hi {{firstName}}, ...` | `{{firstName}}, ...` or open with a situational sentence and reference the name in line 2 |
| `Hello {{firstName}}, ...` | same |
| `Hey {{firstName}}, ...` | same |

The first character of the body should be the firstName merge field or the first word of a situational opener. Never a greeting prefix.

## Unsubscribe / closeout

| Banned (silence = stop) | Allowed (action = stop) |
|---|---|
| `I will take silence as a no` | `A one-word reply works fine if you would rather I stopped` |
| `read no reply as a pass` | `If this is not the right angle, tell me what is` |
| `assume no response means no interest` | `If I misjudged the fit, I would rather know than guess` |
| `If I do not hear back I will leave you alone` | `Just say the word and I will stop` |
